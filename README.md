# 야, 너도 스테이션 편집기

Ya, Nerd Station — 역 시설, 파사드, 보행점, 층간접속, 이동동선과 연계 데이터를 별도 변경 레이어로 관리하는 공개 편집기 프로토타입.

## 실행

Node.js 22.13 이상에서 `npm ci`, `npm run dev`를 실행하고 `http://127.0.0.1:4197/`을 연다. `npm test`는 메모리 저장소에서 검증하며, `npm run build`는 정적 클라이언트와 Worker를 만든다.

대전역(S201801)만 편집 대상으로 허용한다. 서울역(S202103) 심사본·기존 Supabase·영업정보는 이 저장소와 연결하지 않는다. 기본 모델은 변경 레이어에 포함하지 않는다. 가상 샘플은 지도 연결 없이 기능을 시험하기 위한 예제이며 실제 시설이나 통행 가능성을 뜻하지 않는다.

로컬 대전역 실물 지도는 이미 확보한 `../tmp/vworld-daejeon-full-catalog/tileset.json`과 `tiles/B_*.bin`이 있을 때만 읽기 전용으로 사용한다. 이 파일들은 저장소에 포함하지 않는다. 서버로 배포할 때 기본 모델 연결은 VWorld 접근 정책·데이터 이용 조건을 별도로 확인해야 한다. 확인되지 않은 역 목록은 준비 중으로 표시한다.

## 기능

- 구조물 추가, 좌표·크기·회전·색상 편집, 원본 ID 기반 숨김
- 정면·우측·후면·좌측 파사드, PNG/JPEG 업로드
- 출도착 점/영역, 경유점, 시설점, 층간접속점
- 여러 층 엘리베이터 N:N, 단방향/양방향 연결과 순서형 경로
- 날짜·시간별 진입/이탈량, 관측/추정 구분 및 근거
- 서버 저장, 공개 읽기 링크, 별도 초안으로 복사, JSON 가져오기/내보내기
- WebMCP 읽기/층 선택/초안 설정/저장 도구

2m 격자는 참고 좌표이며 자동 장애물 판정이나 최단 경로 생성이 아니다. 원본 에셋 ID를 선택하면 숨김·파사드 레이어를 관리한다. 원본 메시 이동/변형은 직접 수행하지 않으며, 필요한 경우 원본을 숨긴 후 대체 구조물을 추가한다.

## 저장과 보안

로컬은 SQLite와 로컬 업로드 폴더, 배포본은 Sites D1(DB)와 R2(UPLOADS) 바인딩을 사용한다. 서울역의 Supabase와 공유하지 않는다. 로컬 저장 파일은 `data-private/`에 있으며 Git에서 제외한다.

현재 편집 권한은 HttpOnly 쿠키 소유 기반 프로토타입이다. 공개 자료만 넣는다. 쿠키를 잃으면 편집 권한 복구가 안 되므로 JSON을 백업한다. 공개 링크는 읽기만 가능하고 소유자만 원본을 저장한다. 정식 운영 전 계정·복구·접근 로그·악용 방지·정책 검토가 필요하다.

사진은 프로젝트당 100장, 한 장 4MB 이하; 전체 시연 사진 100MB, 전체 프로젝트 200개/문서 약 64MB를 애플리케이션에서 제한한다. 이는 요금 보장이 아니며 서비스 제공자의 별도 사용량·요금 제한이 우선한다. 자동 증설은 하지 않는다. JSON에는 사진 주소만 들어간다. 다른 서버로 이동하거나 원본 공유가 해제된 공개 프로젝트를 복사하면 사진을 다시 업로드해야 할 수 있다.

이 저장소에는 서울역 영업 원자료, 개인 사진 원본, 인증키, 3D 원본 타일이 없다. MIT 라이선스는 이 편집기 코드에만 적용되며 VWorld 데이터·사용자 사진·외부 라이브러리에는 각각의 권리와 조건이 적용된다.

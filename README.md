## 이 도구는 무엇인가

전국 46개 KTX역에 존재하는 VWorld 실내 3D 지도를 기본 모델로 사용하고, 구조물·파사드·시설·보행점·층간연결·이동동선·연계 데이터를 **별도 변경 레이어**로 관리하는 공개 편집기입니다. 원본 3D 모델은 건드리지 않고, 현장에서 바뀐 부분만 덧씌웁니다.

[야!너두 스테이션](https://yanerdstation.kr) 프로젝트의 구축 도구이며, 같은 편집 스키마로 46개 역에 동일 UI를 적용할 수 있습니다.

## 46개 KTX역 — VWorld 실내지도 보유

| 상태 | 역 |
|---|---|
| **연결 완료** | 서울역(`S202103`) · 대전역(`S201801`) |
| **연결 준비 중** | 강릉 · 계룡 · 곡성 · 공주 · 광명 · 광주송정 · 구례구 · 김천구미 · 나주 · 남원 · 논산 · 동대구 · 마산 · 목포 · 부산 · 부전 · 상봉 · 서대구 · 서대전 · 서원주 · 수원 · 순천 · 신경주 · 안동 · 여수엑스포 · 여천 · 오송 · 용산 · 울산 · 원주 · 익산 · 정읍 · 제천 · 진부 · 진영 · 진주 · 창원 · 창원중앙 · 천안아산 · 청량리 · 평창 · 평택 · 포항 · 행신 |

연결 준비 중인 역은 VWorld 건물 ID·중심 좌표·층 목록·기준 고도를 입력하면 바로 같은 UI로 편집할 수 있습니다.

## 실행

```bash
npm ci
npm run dev    # http://127.0.0.1:4197/
npm test       # 메모리 저장소 검증
npm run build  # 정적 클라이언트 + Worker 빌드
```

Node.js 22.13 이상이 필요합니다.

## 기능

- **구조물** — 추가·좌표·크기·회전·색상 편집, 원본 ID 기반 숨김
- **파사드** — 정면·우측·후면·좌측, PNG/JPEG 업로드
- **현장변경** — 추가·이동·숨김·철거 설정 관리
- **시설정보** — 매장·편의시설 등록과 해제 이력
- **발생원점** — 외부 유동인구 원점, 실내 출도착점 연결
- **시설·포인트** — 출도착 점/영역, 경유점, 시설점, 층간접속점
- **층간연결** — 엘리베이터 N:N, 에스컬레이터 단방향/양방향
- **이동동선** — 포인트 순서 기반 경로 연결
- **연계 데이터** — 날짜·시간별 진입/이탈량, 관측/추정 구분 및 근거
- **저장** — 서버 저장, 공개 읽기 링크, JSON 가져오기/내보내기
- **WebMCP** — 읽기/층 선택/초안 설정/저장 도구 (AI 에이전트 연동)

## Station One 서울역 연동

서울역은 Station One의 revision 334 확정 설정을 읽기 전용 API로 불러옵니다. 원점 53개, 출도착 8곳, 시설 281건(활성 115건), 층간연결 84개, 경로 28개, 승인 파사드 94건, 현장 변경 21건을 열람할 수 있습니다. 심사 기간 서버 저장·업로드는 UI와 서버 양쪽에서 차단되며, JSON 내보내기는 허용합니다.

## 저장과 보안

- **로컬**: SQLite + 로컬 업로드 폴더
- **배포**: Cloudflare Workers D1(DB) + R2(업로드)
- 서울역 Supabase와 쓰기 저장소를 공유하지 않습니다
- 편집 권한은 HttpOnly 쿠키 기반 프로토타입이며, 정식 운영 전 계정·복구·접근 로그 검토가 필요합니다
- 사진: 프로젝트당 100장, 한 장 4MB 이하

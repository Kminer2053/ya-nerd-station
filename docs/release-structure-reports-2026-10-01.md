# 새 구조물 제보 처리 보완 · 2026-10-01

## 사용자 흐름

1. 승인자 로그인 → 새로 생김 제보 → **제보 채택 · 작업 시작**.
2. 이름, 층, 좌표, 바닥 높이, 폭·깊이·높이, 방향 및 크기 근거를 입력한다. 초기 크기는 실측이 아닌 예시다.
3. 사진의 네 모서리를 정면에 맞추고 자동 밝기 또는 직접 흐림 처리를 적용한다. AI가 설정되지 않았다면 사람 가림은 수동이다.
4. 비례 입체 모형과 배치 지도를 확인한다. 서울역 배치 지도에는 상자만 표시되며 정면 사진은 별도 입체 모형에서 확인한다.
5. **구조물 초안 저장**. 초안은 재조회·수정할 수 있으며 새 버전이 이전 초안을 대체한다.
6. 저장된 초안의 위치·크기·통행 폭, 사진 공개 가능 여부, 입체 모형을 확인하고 **초안 확정**.
7. **최종 승인**. 서울역은 반영 대기만 저장한다. 다른 역은 공개 지도 변경 레이어에 구조물과 정면 이미지를 반영한다.

채택·초안 저장·초안 확정은 지도 반영이 아니다. 서울역 잠금 해제 이후 자동 반영 작업은 없으며 별도 반영 절차가 필요하다. 실제 사용자의 제보는 이번 구현·테스트에서 채택하거나 승인하지 않았다.

## 범위와 한계

- 사진 기반 정면 보정 + 입력한 규격의 직육면체 구조물. 사진 한 장으로 실제 치수·뒷면·복잡한 3D 형태를 자동 복원하지 않는다.
- 정면은 긴 변 1024px, 짧은 변 최소 32px에 맞추고 JPEG/PNG로 저장한다. 이는 매체 규격이 없는 새 구조물의 시연용 최적화 기준이다.
- 기존 파사드 교체는 기존 슬롯의 픽셀 규격을 유지한다.
- 원본 사진은 기존과 같이 제보자·승인자만 열람한다. 미승인 초안 사진과 보정 메타정보는 승인자만 열람한다.
- 승인 후 결과 이미지는 공개되므로 얼굴·개인정보와 사진 공개 권한을 승인자가 확인해야 한다.
- 대전 등 공개 지도/편집기의 새 역 초안은 승인된 구조물을 읽는다. 서울역 Station One의 심사 고정본은 변경하지 않는다.

## 저장과 검증

- 기존 D1 proposals/station_layers JSON 필드를 사용하므로 마이그레이션은 추가하지 않는다. DB.batch 지원 필수.
- 승인: 조건부 확보 → JSON 한 키 병합 → 제보 이력 → 감사 → 최종 상태를 하나의 트랜잭션으로 처리한다.
- 초안: 보고서 수정 시각을 비교해 동시 저장 충돌을 차단한다. 이전 초안은 superseded로 보관한다.
- 근접한 새 구조물 제보는 자동으로 같이 완료하지 않는다.
- `npm test`, `npm run test:reports`, `npm run build`, `git diff --check`.
- 신규 회귀: 채택 필수, 재조회·버전 충돌, 사진 소유권·규격·좌표 검증, 초안 비공개, 확인 전 승인 거부, 동시 승인, DB 실패 시 rollback, 서울 잠금, 이웃 제보 독립성, 크기 변경 시 얼굴 흐림 재매핑.

# 서울역 관리자 승인 제보 지도 반영 — 2026-10-05

사용자 요청에 따라 서울역의 심사기간 지도 반영 제한을 해제한다.

- 제보 채택 → 보정·구조물 초안 → 위치/개인정보/모형 확인 → 관리자 최종 승인 절차 유지.
- 최종 승인 후 서울역도 `applied` 처리하고 `station_layers`에 저장한다.
- 미승인 초안·제보 사진 원본은 공개 지도에 노출하지 않는다.
- 공개 편집기의 직접 원본 프로젝트 저장·업로드 보호는 유지한다. `jury_locked: false`와 `direct_save_locked: true`를 구분한다.
- 기존 확정 데이터 337과 기준 파사드 94장은 보존하고, 승인된 파사드만 해당 면에 덮어 표시한다. 신규 승인 구조물은 별도 지도 레이어에 표시한다.
- 서울역 편집기에서 기준 자산과 승인된 구조물을 함께 불러온다. 임시 수정은 승인 레이어와 분리된다.
- 서비스는 승인 레이어를 처음 연결할 때와 5분마다 읽는다. 승인 직후 지도 새로고침으로 확인할 수 있다.
- 편집기 연결 장애 때 기존 서울역 기준 모델/파사드와 마지막 성공한 승인 레이어를 유지한다.

## 배포 전 확인

2026-10-05 운영 제보함 조회: 서울역 검토 대기 1건, 반영 대기 0건, 반영 완료 0건. 과거 승인 대기 이관 대상이 없다. 실제 검토 중 제보를 임의로 채택/승인하지 않았다.

검증: 공개 원본 저장 차단, 승인자 인증/동일 사이트 요청, 미승인 이미지 비공개, 구조물 확인 체크, 최종 승인 후 서울역 파사드·구조물 노출, 동시 승인 충돌 및 원자적 저장 실패 복구. 서비스 기준 면 배치·UV·특수 시설 키 보존과 구조물 사진 면/층 메타데이터를 별도로 검증한다.

배포 순서: 공개 편집기 → 서비스. GitHub 편집기 저장소와 서비스의 `toolkit/` 소스 미러를 함께 갱신한다. Sites는 공식 배포 절차를 사용하며 원격 직접 push는 하지 않는다.

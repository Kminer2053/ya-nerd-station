# 다면 사진 제보 입력·검토 보완 · 2026-10-05

## 작업 범위

사람이 작업 종류를 판단하고 사진 기반 작업을 연결하기 위한 다면 입력과 보정·검토 흐름을 추가한다. 자율 작업 큐, 장애물 자동 삭제, 복잡한 구조물 자동 복원 및 추가 자료 자동 요청은 이번 변경에 포함하지 않는다.

## 제보 입력

- 정면·좌측면·우측면·후면·주변을 구분해 총 1~5장. 같은 면의 복수 사진도 허용한다.
- 좌측/우측 기준은 정면을 마주 보고 서 있는 방향이다.
- 파사드 교체와 새 구조물은 정면 사진 필수. 새 구조물에는 좌측 또는 우측 사진도 권장하며, 촬영 불가한 면은 설명에 남긴다.
- 주변 사진은 배치·통행 공간 확인용이다. 구조물 표면의 이미지로 사용하지 않는다.
- 사진 준비·전송 중 입력과 단계 이동을 잠가 준비 중인 사진이 제출에서 빠지지 않게 한다.
- 원본을 2048px JPEG로 재인코딩하며 EXIF/GPS를 제거한다. 공개 제보함에는 기존 48px 모자이크만 표시한다.

## 보정·검토·승인

- 승인자는 사진 번호와 촬영면을 확인하고 면별 네 모서리, 자동 밝기, 사람 가림·수동 흐림을 따로 편집한다.
- AI 키가 설정된 경우 최대 5장을 함께 분석한다. 누락 파일 때문에 사진 순서가 달라져도 사진 ID로 모서리·사람 영역을 원본에 연결한다.
- 새 구조물은 실제 사진이 있는 면을 보정 후 하나의 초안으로 저장한다. 정면·후면은 폭×높이, 좌·우측면은 깊이×높이로 최적화한다. 각 면의 긴 변은 1024px이다.
- 면을 바꾸거나 저장된 초안을 다시 열어도 사진 ID·모서리·밝기·개인정보 가림 설정을 복원한다. 규격 변경 시 흐림 영역을 새 출력 크기에 맞춘다.
- 촬영하지 않은 면은 기본 색상으로 남긴다. 실제 치수는 입력한 근거와 승인자 확인을 사용하며 사진만으로 실측값을 추정 확정하지 않는다.
- 저장된 모든 면의 보정 이미지와 입체 모형을 확인한 뒤 초안을 확정하고 최종 승인한다. 최종 승인 전에는 지도를 바꾸지 않는다.

## 데이터와 개인정보

- 새 마이그레이션 `0003`은 `report_photos.view_role`만 추가한다. 과거 사진은 `unknown`(면 미지정)이며 임의로 정면으로 바꾸지 않는다.
- 기존 정면 이미지 주소는 유지한다. 좌·우·후면은 `/api/public/proposal-images/:id/:face`로 전달한다.
- 미승인 면별 이미지 및 보정 메타정보는 승인자만 볼 수 있다. 공개 경로는 최종 승인 상태와 실제 저장된 면을 모두 확인한다.
- 다른 제보의 사진, 잘못 지정한 면, 주변 사진을 표면으로 사용하는 요청과 틀린 출력 규격을 거부한다.
- 최종 승인 후 보정 이미지는 공개되므로 각 면의 얼굴·개인정보·사진 사용 권한을 승인자가 확인해야 한다. 자동 모자이크가 완전한 비식별화를 보장하지 않는다.
- 새 AI 서비스 키나 승인자 비밀 값은 추가·변경하지 않는다. AI 미설정이면 규칙 정리와 수동 보정을 사용한다.

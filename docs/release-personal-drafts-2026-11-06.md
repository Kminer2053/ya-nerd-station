# 46개 역 개인 초안 저장 — 2026-11-06

2번 작업의 개인 프로젝트 범위다. 서울역도 다른 역처럼 개인 초안을 생성·수정·저장하고 파사드 사진을 업로드한다. 운영 배포나 원본 데이터 삭제는 하지 않는다.

## 저장과 운영 반영

- `/api/projects` 생성은 항상 비공개다. 기존 브라우저 소유자 쿠키와 해시로 프로젝트·사진 접근을 검사한다.
- 소유자는 리비전을 확인하여 수정한다. 다른 브라우저는 비공개 초안과 파일을 읽지 못한다. 같은 리비전의 오래된 수정은 충돌로 중단한다.
- 초안 공유를 켜면 다른 사람은 읽거나 자기 프로젝트로 복사할 수 있다. 공유받은 원본의 수정·업로드 권한은 생기지 않는다. 복사본은 비공개로 시작한다.
- 개인 초안 저장·업로드는 `editor_projects/editor_files`에만 기록한다. 운영 공개 지도 레이어와 제안 승인 기록은 이 경로에서 바꾸지 않는다.
- 운영 지도에 반영할 변경은 사진 제보 → 수정안 검토 → 운영자 최종 승인 경로를 사용한다. `/api/seoul/snapshot`과 시간별 기준 자료는 계속 조회 전용이다.

서울역에 결합되어 있던 잠금 조건은 개인 프로젝트 생성·수정·업로드에서 해제했다. 호환 함수 `saveLocked()`는 개인 초안을 잠그지 않는다. 시간별 자료 보기, 원본 구조 설정 JSON 열람, 원본 참조·시설·동선은 유지했다. 서울 스냅샷 어댑터는 입력 자료를 복사하여 초안 편집이 불러온 기준 객체를 바꾸지 않게 한다.

## 46개 역 선택

기존에 검증해 둔 `stations`의 46개 역 ID·좌표·층·기준 고도를 그대로 사용한다. 주편집기의 서울·대전 두 개 하드코딩 목록을 전체 목록으로 바꿨으며, 사용자가 다른 44개 역의 연결 JSON을 다시 입력할 필요가 없다. 새 초안은 현재 선택한 역의 기준 자료에서 시작한다. 직접 입력으로 추가 역을 연결하는 기존 기능은 남겨 둔다.

저장·불러오기 URL은 로컬 미리보기의 승인된 서비스 주소 설정을 유지한다. 사진의 저장 주소는 프로젝트에 남기고, 서울역 iframe의 비공개 사진 미리보기는 편집기에서 접근 가능한 사진만 화면 전송용으로 변환한다.

## 승인된 사진 면의 개인 편집

새로 등록하여 승인된 사진 면도 역을 열 때 개인 초안의 시설물·파사드 목록에 가져온다. 개인 초안에서 이름·사진·폭·높이·위치·방향을 바꾸거나 저장하고 다시 열 수 있다. 면만 확인된 자료는 평면 하나로 가져오며 실제 시설의 깊이를 추정한 상자로 제시하지 않는다. 편집용 두께는 화면에서 따로 안내한다.

공개 면의 중심 고도는 개인 시설물의 바닥 고도로 변환하고, 방향·좌우 사진 좌표를 맞춘다. 승인 당시의 중심 위치·규격·치수 확인 방법은 별도 참조 정보에 남긴다. 공개 자료에 세부 근거가 없으면 없다고 표시한다. 기존 서울역 시설물과 같은 식별자는 한 항목만 유지하고, 새 사진 면에 원본 시설물 ID를 만들어 붙이지 않는다.

가져온 개인 면을 표시하는 동안 같은 승인 면을 중복 표시하지 않는다. 이 선택과 개인 사진·치수 수정은 미리보기와 개인 프로젝트에만 적용된다. 원래 승인 면과 공개 지도는 최종 승인 경로 없이 바뀌지 않는다.

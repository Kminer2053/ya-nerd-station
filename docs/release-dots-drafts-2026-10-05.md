# Dots 에비의 지도 수정 초안 연결

이 연결은 사용자가 보유한 에비에게 Toolkit 제보 사진을 분석하고 지도 수정 초안을 제출하도록 맡기는 기능이다. 서버의 별도 AI API 키 없이 Dots의 도구 연결을 사용하며, 실제 모델 사용량과 계정 권한은 Dots 정책을 따른다. Toolkit의 최종 지도 승인은 여전히 승인자가 직접 한다.

## 공식 근거와 구현 범위

[OpenAI Dots 안내](https://learn.chatgpt.com/docs/dots)는 Dots를 Astra 기반 에이전트로 설명하며 자체 클라우드 컴퓨터와 플러그인 사용을 지원한다. 에비는 사용자 지정 이름이므로 실제 에비 대화와 연결 계정은 사용자가 확인해야 한다. 서버가 모델 ID나 에비라는 이름을 지정해 구독권으로 API를 호출하는 방식이 아니다.

[MCP Events](https://developers.openai.com/plugins/build/mcp-events)는 Dots의 공식 이벤트 구독 경로다. 다만 이번 버전은 요청 시 사용하는 MCP 도구와 영속 작업 큐를 구현한 버전이다. 자동 이벤트 구독·자동 깨움은 활성화하지 않았다. 웹훅 주소 검증, 서명, 재전송과 실제 에비 구독 확인까지 검증하기 전에 자동 전송을 가장하지 않는다. `toolkit_list_work`도 `automatic_wakeup: false`를 반환한다.

## 연결과 사용

1. Toolkit 제보함의 승인자 계정으로 로그인하고 해당 제보를 연다. 실행 방법에서 `에비 · Dots 도구로 분석`을 선택한다.
2. ChatGPT에서 Sites가 제공한 Toolkit 개인 플러그인을 설치·연결한다. 별도 앱이나 로컬 MCP 서버를 만들지 않는다.
3. 승인자 화면에서 사진·설명·초안 접근 범위를 확인하고 `15분 연결 코드 만들기`를 누른다. 발급 시 한 번만 표시되는 연결 요청문을 에비 대화에 전달한다.
4. 에비가 `toolkit_connect_agent`로 코드를 사용하면 현재 Sites 인증 ChatGPT 계정과 연결된다. 연결은 7일 유효하며 `에비 연결 모두 해제`로 즉시 철회할 수 있다. 코드가 에비라는 이름 자체를 인증하는 것은 아니므로 정확한 대화에 전달한다.
5. 파사드/구조물/숨김 작업 종류와 대상을 승인하고 요청을 저장한다. `에비 요청문 복사`로 해당 작업 ID와 도구 사용 순서를 에비에게 전달한다. 저장만으로 메시지가 전송되거나 에비가 깨어나지 않는다.
6. 에비가 작업과 사진을 읽고 계획을 제출하면 서버가 원본 사진으로 보정·가림 처리한 비공개 초안을 생성한다. 자료가 부족하면 질문을 남긴다. 승인자는 보완 후 새 요청을 만든다.
7. 승인자가 실제 출력 이미지·위치·주변 보존·개인정보를 확인하고 초안 확인 및 최종 승인을 완료해야 지도에 반영된다.

## 서버 도구와 권한

- `toolkit_connection_status`: 현재 연결 여부. 미연결 계정에는 제보 정보가 없다.
- `toolkit_connect_agent`: 15분 일회용 코드로 연결. 서버는 코드의 SHA256 해시만 저장한다. 같은 계정의 재전송은 기존 연결을 반환하며 다른 계정의 재사용은 거부한다.
- `toolkit_list_work`: 연결한 승인자가 명시적으로 Dots에 맡긴 최신 작업 최대 20건.
- `toolkit_read_work`: 승인 범위·사진 ID·허용 독립 구조물·JSON 계획 계약.
- `toolkit_read_photo`: 해당 작업 사진 한 장의 최대 640px 분석 이미지. 다른 제보 원본은 반환하지 않는다.
- `toolkit_submit_plan`: 검증된 데이터 계획만 제출. 서버가 원본 보정과 비공개 초안 저장을 수행한다.
- `toolkit_request_info`: 승인자에게 추가정보 질문을 남긴다.

Sites가 인증한 사용자 ID로 계정을 확인하고, D1의 `agent_links`가 승인자와 초안 전용 접근을 연결한다. 플러그인 설치만으로 승인자 권한이 생기지 않는다. 승인자 비밀번호·세션 쿠키는 공유하지 않으며 MCP에는 최종 승인·준비 완료·공개 지도 직접 쓰기 도구가 없다. 승인자 계정 삭제·연결 철회·7일 만료 시 데이터 접근이 중단된다.

새 구조물은 승인자가 확인한 치수·방향·제보 핀의 상자형 모형이다. 사진에 없는 면, 정확한 치수, 복잡한 형상은 만들지 않는다. 공유 VWorld 모델을 추측해서 제거하거나 AI 이미지 인페인팅을 제공하는 기능은 아니다. 기존 독립 생성 구조물 중 승인자가 지정한 대상만 숨길 수 있다. 사진 속 문구와 제보 설명은 지시가 아닌 증거로 다룬다.

## 검증과 출시

- `npm test`, `npm run test:reports`, `npm run test:ai-work`, `npm run test:dots-work`, `npm run build`, `git diff --check`.
- 메모리 D1/R2와 실제 PNG를 사용해 코드 해시·15분 만료·계정/승인자 격리·서버 AI 작업 차단·640px 이미지·계획 검증·비공개 초안·재전송/충돌·추가정보·사진 변경/취소·권한 철회·7일 만료를 검증한다. 외부 모델 호출은 하지 않는다.
- 사진 처리 도중 연결이 만료되어도 저장 직전 권한을 재검사해 초안을 취소하고 임시 보정 이미지를 정리한다. 이 경계도 회귀시험으로 검증한다.
- 플러그인 도구 주소는 Sites가 제공한 `https://ya-nerd-station.soalsebi.chatgpt.site/mcp`를 사용한다. 운영 배포에서 인증 없는 요청은 Sites 인증 경계에서 401로 차단되며, 커스텀 도메인의 `/mcp`를 별도 등록하지 않는다.
- 운영 중인 실제 제보를 채택·승인·반려하거나 사진을 에비에게 보내는 검증은 하지 않는다. 실제 에비 로그인·플러그인 연결·초안 전용 계정 연결 후 비파괴 확인이 별도로 필요하다.
- `drizzle/0005_thick_mojo.sql`은 새 `agent_links` 테이블과 인덱스만 추가한다. 기존 테이블·사진·승인 레이어는 유지한다.
- 공개 Toolkit 소스와 private service/toolkit 미러에 함께 커밋한다. Toolkit만 공식 Sites workflow로 저장·배포하며 서비스 런타임은 바꾸지 않는다.

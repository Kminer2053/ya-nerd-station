# Dots 대화 중심 관리자 작업 흐름 — 2026-10-06

## 방향 교정

수동 작업 화면 위에 채팅을 추가하는 방식은 요청을 충족하지 않았다. 기본 관리자 화면을 **사진·파일과 대화 → 수정안 미리보기 → 사람의 최종 승인**으로 교체한다.

- 기본 UI에서 작업종류·치수·방향·사진 모서리·밝기·면별 보정 폼과 수동 작업대를 렌더링하지 않는다. 호환용 서버 기능은 삭제하지 않는다.
- Dots 연결 관리는 채팅 안에 둔다. 연결되지 않았거나 만료된 경우 실제 작업 전송을 막고 입력을 유지한다.
- 최초 전송에서 초안 작업의 범위를 한 번 확인한다. 종류/치수 폼 없이 서버가 제보의 층·핀과 12m 이내 등록 파사드/독립 구조물 목록을 고정하고 `conversation` 작업을 생성한다.
- 에비는 허용한 범위에서 `facade|structure|removal` 중 실제 작업 종류를 선택한다. 추정 치수는 estimated, 같은 층·핀 2m 이내, 0.1~30m, 근거·불확실성으로 검증한다. 파사드는 서버의 허용 목록만 선택한다.
- 추가 답변·사진은 대화로 보낸다. 기존 작업/초안을 교체하고 최신 메시지에 연결된 초안만 저장·최종 승인할 수 있다.
- 저장된 수정안의 입체 모형, 보정 전후, 추정 근거와 실제 변경 대상을 읽기 전용으로 확인한다. 지도 미리보기를 클릭해도 초안 좌표가 바뀌지 않는다.
- 사람이 위치/개인정보/미리보기/변경 대상을 확인하고 최종 승인하면, 서버가 한 트랜잭션에서 검사·반영한다. 별도 ‘초안 확정’ 화면을 거치지 않는다.
- 이전 수동 작업은 자동으로 권한을 넓히지 않는다. 대화 작업을 명시적으로 맡길 때만 새 범위로 교체한다. 이전 초안은 접힌 기록으로 남긴다.

## 아직 완료하지 않은 사항

- **Ebi 자동 호출은 미연결**이다. 요청 저장과 실제 에비 답변은 구분한다. 유료 중계 구성 승인과 실제 MCP Events 구독/호출 왕복 검증이 필요하다.
- 바닥 데칼은 미지원이며 다른 수직 구조물로 대신 생성하지 않는다.
- 사진에 없는 면을 만들거나 공유 원본 모델을 추측해 제거하지 않는다. 구조물은 간단한 치수 기반 모형이며 사진 한 장으로 실제 3D 형상을 자동 복원했다고 주장하지 않는다.

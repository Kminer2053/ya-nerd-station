# AI 초안 작업 — 2026-10-05

## 실제 구현 범위

- 제보함에서 승인자가 `파사드 교체 / 구조물 생성 / 장애물 숨김`을 선택하고 AI 분석 전송·작업 시작을 명시 승인한다.
- D1 `report_jobs`에 승인 의도·입력·질문·결과·실패·취소를 저장한다. 요청 처리 후 서버 작업을 이어가며 화면은 상태만 조회한다. 3분 이상 중단된 작업은 재시도 가능한 실패로 표시하며 유료 요청을 몰래 다시 실행하지 않는다.
- 명확한 사진 면마다 AI가 네 모서리·사람/개인정보 영역을 반환한다. 서버가 원본에서 먼저 모자이크한 뒤 원근·밝기 보정해 불변 PNG 결과를 R2에 저장한다. 주변 사진은 배치 근거이며 표면에 입히지 않는다.
- 승인자가 입력한 폭·깊이·높이·방향과 제보 핀으로 상자형 구조물 데이터를 생성한다. 실측/추정 근거를 표시한다. 숨겨진 면·치수·복잡한 실제 형상을 사진에서 임의로 확정하지 않는다.
- 부족한 치수·사진·파사드 자리·독립 제거 대상은 `needs_info` 질문으로 승인자에게 요청한다. 승인자는 답변·치수 입력 및 보완 사진(제보당 총 5장) 후 새 초안을 요청한다.
- 장애물은 이 시스템에서 독립 생성·승인된 `structure-<proposal ID>`만 후보로 제공하며 승인자가 허용한 대상 중 AI가 선택한다. 같은 층·제보 핀 12m 이내, ID/key 일치, 원본 `source_id/source_record` 없는 대상만 허용한다.
- 원본 VWorld 모델은 여러 매장·삼각형에서 ID를 공유한다. 원본 공유/부분 모델은 자동 제거를 지원하지 않으며 정확한 대상 범위의 정밀 확인을 요청한다. 임의로 가까운 슬롯의 TD_ID를 숨기거나 기존 합성 셰이더를 덮어쓰지 않는다.

## 최종 승인·복원

- 모든 자동 결과는 `draft`이며 승인 전 공개 지도는 바뀌지 않는다.
- 저장된 면별 이미지/모형 또는 숨김 전후 대상 목록과 위치·개인정보·주변 보존을 확인하면 `ready`, 다시 최종 승인하면 공개 승인 레이어에 반영한다.
- AI는 승인 권한·임의 실행 도구·SQL·URL 가져오기 권한을 갖지 않는다. 제보 문구·사진 속 문구는 명령이 아닌 증거다. 반환값은 알려진 사진 ID·면·볼록 모서리·정상 bbox·허용 대상 ID로 검증한다.
- 제보 버전 및 각 대상의 승인 전 JSON을 트랜잭션에서 비교한다. 같은 대상의 동시 수정이나 늦은 AI 결과는 중단한다. 다른 대상의 승인 결과를 전체 레이어 교체로 덮지 않는다.
- 숨김은 원본 삭제가 아니다. 자동 숨김·생성의 `되돌리기`는 해당 대상만 과거 상태로 복원한다. 승인 뒤 대상이 수정됐으면 복원을 중단한다. 원본 사진과 감사 기록을 보존한다.
- AI 검출은 개인정보 제거의 보증이 아니다. 모든 면의 실제 출력물을 사람이 확인하고, 누락이 있으면 수동 보정 작업대에서 수정·새 초안 저장 후 승인한다.

## 운영 설정과 현재 한계

- AI 자동 작업에는 `AI_API_KEY` 비밀 설정, `AI_PROVIDER`(`anthropic/openai`), 실제 이용 가능한 비전 모델 ID `AI_MODEL`이 모두 필요하다.
- 이번 작업 시작 당시 운영 사이트에는 `APPROVERS`만 설정되어 있었다. API 설정이 없으면 `needs_config`로 안내하며 AI 완료를 가장하지 않는다. 키는 별도 비밀 설정에 등록하고 소스·로그·채팅에 저장하지 않는다.
- 제공자를 선택하고 안전하게 비밀 설정을 완료한 뒤 실제 모델 응답·Worker 처리 시간·비용을 운영 테스트해야 한다. 이번 검증은 실제 PNG/JPEG와 모의 AI 응답으로 수행한다. 실제 운영 AI 호출 성능은 API 설정 전 검증되지 않았다.
- 한 작업 사진 최대 5장, 긴 변 2048px, 분석 축소 640px, 분석 이미지 합계 5MB, 출력 긴 변 최대 1024px, 면별 4.8MB/전체 16MB 한도. 큰 원본 슬롯 규격은 수동 보정으로 안내한다. API 호출은 20초 한도이며 승인자별 하루 40회다.
- PNG는 단일 IHDR·8bit·허용 chunk·압축 해제 예상 바이트 상한을 먼저 확인한다. 압축 ICC/부가자료 및 비표준 PNG는 JPEG 재제출을 요청한다. 처리 시 Buffer가 없는 Worker 환경을 테스트한다.

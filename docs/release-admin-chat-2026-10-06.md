# 관리자 에비 작업 채팅 — 2026-10-06

## 반영 범위

- 제보별 승인자 전용 작업 대화창: 텍스트, 다중 사진·파일, 질문 답변, 실제 진행 상태, 초안 검토 이동.
- JPEG/PNG, PDF, UTF-8 TXT/MD/CSV/JSON, DOCX/XLSX. 파일당 4MB, 전송당 8개, 승인자·제보별 80개. 전체 저장 한도는 기존 REPORT_STORAGE_MB 안에서 관리한다.
- 작성 중 내용은 앱 내부 갱신과 제보 전환에서 보존한다. 로그아웃하면 비공개 작성 내용·첨부 미리보기를 지운다. 브라우저 전체 재로드는 미전송 작성 내용을 초기화한다.
- 에비 읽기/답변 도구: toolkit_read_conversation, toolkit_send_message, toolkit_read_file. 기존 사진 읽기·보정·초안 제출 도구를 유지한다.
- 에비의 보완 질문은 대화 이력에 저장한다. 관리자 답변은 승인된 작업 종류·위치·허용 ID를 복사한 후속 작업으로 이어진다. 이전 초안은 무효화하고 최종 공개 지도는 바꾸지 않는다.
- 관리자가 명시적으로 추정을 허용한 새 구조물은 근거·불확실성을 기록한 크기 초안을 받을 수 있다. 같은 층·제보 핀 2m 이내, 0.1~30m 치수, estimated 표시를 검증한다. 이미 입력한 형상은 AI가 바꾸지 못한다.
- 수평 바닥 데칼은 아직 지원하지 않는다. 사진에 없는 면이나 허용 목록 밖의 공유 원본 장애물을 만들어 내거나 제거하지 않는다.

## 자동 연결 상태

이 배포는 에비를 자동으로 깨우지 않는다. 관리자 메시지를 D1/R2의 비공개 대기열에 저장하고, 연결된 에비가 도구를 호출하면 공동 대화에 응답할 수 있다. 기존 Dots 비공개 채팅을 임베드하거나 전체 대화를 복사하지 않는다.

OpenAI MCP Events는 공식 자동 깨움 경로다. 현재 Sites fetch만으로 외부 콜백의 연결 시 DNS 검증·검증 IP 연결·원 호스트 TLS 검증을 충족하는 발송 경로는 확인되지 않았다. 별도 중계 계층과 에비 측 실제 이벤트 구독을 구성·검증하기 전에는 자동 연결을 활성화하거나 events 기능을 광고하지 않는다.

참고: https://developers.openai.com/plugins/build/mcp-events
